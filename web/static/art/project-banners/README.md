# Project banners

Eight landscape 3D product scenes for the home-page project journey. They contain
no people, names, logos or readable UI; project titles and links remain HTML.

The `*-banner-v1.webp` files are the 1536 × 1024 masters. Run
`npm run art:variants` from `web/` after adding or replacing a master to create
responsive AVIF and WebP files. The separate portrait covers in
`../project-covers/` remain in use on individual case pages.
