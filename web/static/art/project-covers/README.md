# Project comic covers

Five full-bleed 1024×1536 WebP illustrations for the project issues. Cover
titles, captions, issue numbers and language controls remain live HTML; these
files deliberately contain no words or logos.

| File                          | Project                   | Visual story                                      |
| ----------------------------- | ------------------------- | ------------------------------------------------- |
| `segispro-cover-v1.webp`      | SEGISPRO                  | HSE records converging into one operational flow  |
| `formarpro-cover-v1.webp`     | FORMARPRO                 | Learning, evaluation and verifiable certification |
| `transmeralda-cover-v1.webp`  | TRANSMERALDA × COTRANSMEQ | Two transport operators sharing one core          |
| `developer-os-cover-v1.webp`  | DEVELOPER OS              | Human-controlled agents, validation and worktrees |
| `gym-vancouver-cover-v1.webp` | GYM VANCOUVER             | Four school communities sharing one source        |

## Generation specification

Each image used the existing `julian-cover-freelancer-v1.webp` as the character
and comic-language reference, plus the corresponding `/projects/*.webp`
product capture as its domain and palette reference.

Shared prompt:

> A new 2:3 full-bleed premium hand-inked modern superhero-comic illustration
> featuring the same recognizable young Colombian freelance developer from the
> approved #1227 cover: curly dark hair, glasses, energetic foreshortening,
> expressive ink, Ben-Day halftone and vintage offset texture. Preserve calmer
> upper and lower zones for live HTML cover furniture. Image only: no text,
> letters, numbers, logos, watermarks, readable UI, branded superhero costume,
> photorealism or malformed hands.

Project directions:

- **SEGISPRO:** dark HSE command room; profiles, planning, evidence, documents
  and billing converge through electric-blue paths into one system.
- **FORMARPRO:** a continuous path of courses, assessment and a verified
  certificate; warm cream, royal blue and yellow; diverse adult learners.
- **TRANSMERALDA × COTRANSMEQ:** two green transport lanes and fleets converge
  into one operating map while keeping separate field and dispatch identities.
- **DEVELOPER OS:** a local mission-control console; isolated agent worktrees,
  red rejected branch, green validated branch, review shield and human control.
- **GYM VANCOUVER:** a shared digital school ledger connects administrators,
  teachers, students and families in a warm cream, navy and school-red campus.

Generated with the built-in image generation tool and optimized to WebP at
quality 88 for runtime use.
